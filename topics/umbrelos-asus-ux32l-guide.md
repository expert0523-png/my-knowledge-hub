## 1. 什麼是 umbrelOS？

**umbrelOS** 是目前公認最優雅、最像「家用版 iOS / macOS」的開源家庭伺服器系統（Home Server OS）。

### 核心特點：
- **極致美觀的 Web 介面**：不需要碰複雜的 Linux 黑色終端機指令，用瀏覽器打開就像一台平板電腦桌面。
- **一鍵安裝 App Store**：背後全部容器化（Docker），想架雲端硬碟、照片備份、VPN、廣告攔截器、甚至是 Bitcoin 節點，點一下「Install」就自動跑起來。
- **完全去中心化與個人隱私**：所有檔案、照片、密碼全部存放在你客廳/房間的這台筆電上，不經過第三方伺服器。
- **支援 x86_64 PC 與筆電**：早期專門跑在樹莓派（Raspberry Pi），但現在官方已完整支援一般 PC 與舊筆電。

## 2. 硬體評估：ASUS Zenbook UX32L 適合嗎？

**結論：非常適合做為輕量至中度負載的家用伺服器！**

### 筆電規格分析（ASUS UX32LA / UX32LN 系列）：
- **CPU**：Intel 第 4 代 Core i5-4200U / i7-4500U（2 核心 4 執行緒，64-bit x86 架構，滿足官方雙核以上標準）。
- **RAM**：通常為 4GB ~ 8GB DDR3（官方建議 4GB 以上，日常跑 5~10 個 Docker 服務相當足夠）。
- **硬碟**：內建 2.5 吋 SSD 或混合硬碟（若原本是傳統硬碟，強烈建議換成便宜的 SATA SSD，速度會提升數倍）。
- **優勢**：
  1. **自帶不斷電系統（UPS）**：筆電本身有電池！家裡短暫跳電或拔插頭時伺服器不會瞬間斷電損壞資料。
  2. **內建螢幕與鍵盤**：剛安裝或排查故障時不需要外接螢幕。
  3. **超省電**：低電壓版 CPU（TDP 15W），待機耗電僅約 5~10W，24 小時開機一個月電費不到幾十元台幣。

## 3. 安裝前準備與關鍵注意清單

### ⚠️ 最重要的三件事：
1. **資料備份**：安裝 umbrelOS 會**完全格式化**筆電的內部硬碟，原本筆電裡的 Windows 和資料會全部被清除！
2. **網路線（非常重要）**：
   - **umbrelOS 首次安裝設定「必須插著有線網路（Ethernet）」連接到家用路由器（小烏龜或分享器）**。
   - *注意*：UX32L 機身很薄，通常沒有原生 RJ-45 孔，需要準備一條 **「USB 轉 RJ45 有線網路轉接頭」**（當初買筆電原廠盒裝有附，或任何市售 USB 網卡皆可）。
3. **準備工具**：
   - 一支 **至少 4GB 以上的 USB 隨身碟**（隨身碟資料也會被清空）。
   - 另一台可正常上網的電腦（用來下載映像檔與燒錄）。

## 4. 手把手安裝步驟

### 步驟 A：製作 umbrelOS 開機安裝隨身碟
1. 前往 umbrelOS 官方網站下載：
   👉 **[umbrelOS for amd64 USB Installer](https://umbrel.com/)**（下載 `.iso` 或 `.img` 安裝檔）
2. 下載免費燒錄軟體：👉 **[BalenaEtcher](https://etcher.balena.io/)** 或 **Rufus**。
3. 插上隨身碟，打開 BalenaEtcher：
   - 點選 **Flash from file**（選擇下載的 umbrelOS 安裝映像檔）。
   - 點選 **Select target**（選擇你的隨身碟）。
   - 點選 **Flash!** 等待進度跑完。

---

### 步驟 B：設定 ASUS UX32L 的 BIOS 開機順序
1. 將燒錄好的隨身碟插上 ASUS UX32L。
2. 將 USB 網卡與網路線接好，另一端插上路由器。
3. **進入 BIOS**：
   - 筆電完全關機。
   - 按住鍵盤上的 **`F2`** 鍵不放，同時按下 **電源開關**，直到進入藍灰色的 BIOS 設定畫面再放開。
4. **BIOS 關鍵調整**：
   - 切換到 **`Security`** 分頁：找到 **Secure Boot Control**，設為 **`Disabled`**（關閉安全開機，umbrelOS 才進得去）。
   - 切換到 **`Boot`** 分頁：
     - 將 **Fast Boot** 設為 **`Disabled`**。
     - 如果有看到 **Launch CSM**，建議保持 UEFI 模式。
   - 按 **`F10`** 儲存並離開。
5. 重開機時狂按 **`Esc`**（ASUS 快捷開機選單），在清單中選擇你的 **`UEFI: [隨身碟名稱]`** 按 Enter 開機。

---

### 步驟 C：自動安裝至筆電內部硬碟
1. 開機後會進入 umbrelOS 的文字終端選單。
2. 系統會偵測到筆電的硬碟清單（例如顯示 `1. ATA SanDisk SSD 128GB`）。
3. 輸入對應的數字（例如 `1`），按下 Enter。
4. 系統會跳出警告確認是否抹除硬碟，確認後開始寫入。
5. 安裝完成後，螢幕會提示請你**拔掉 USB 隨身碟**並按下任一鍵重新啟動。

## 5. 首次開機、登入與基礎操作指南

1. **開機**：
   - 筆電重開機後，維持插著電源與網路線。
   - 螢幕最終會停留在一行顯示：
     `umbrelOS started. Welcome to your personal server.`
     並顯示它取得的區網 IP（例如 `192.168.1.120`）。
2. **從其他裝置連入（手機 / 平板 / 另一台電腦）**：
   - 確保你的手機或電腦與筆電連在同一個家用 Wi-Fi / 區域網路。
   - 打開瀏覽器（Chrome / Safari），在網址列輸入：
     👉 **`http://umbrel.local`**
     *(如果打不開，直接輸入螢幕上顯示的 IP，例如 `http://192.168.1.120`)*
3. **歡迎精靈設定**：
   - 輸入伺服器名稱、建立你的管理員帳號與密碼（請牢記）。
   - 進入後，就會看到超漂亮的 umbrelOS 桌面！

## 6. 筆電當伺服器的必備設定（關鍵細節！）

用舊筆電當 24 小時開機伺服器，有幾個必做調整：

### ① 筆電蓋子合上不要休眠
Linux 預設合上筆電螢幕可能會進入睡眠：
- **最簡單做法**：在初期測試時，**先把筆電螢幕半開著**。
- **進階做法（修改 systemd 設定）**：
  若想完全合蓋藏在角落，可以透過 SSH 登入 umbrelOS：
  ```bash
  ssh umbrel@umbrel.local  # 密碼為你設定的管理員密碼
  sudo nano /etc/systemd/logind.conf
  ```
  找到 `#HandleLidSwitch=suspend`，改成：
  `HandleLidSwitch=ignore`
  存檔重啟，之後就算蓋上螢幕，伺服器依然會全速運作且關閉螢幕背光省電！

### ② 散熱與電池保養
- 筆電請放在通風良好的地方，不要放在棉被或地毯上，最好底部稍微墊高以利散熱。
- 由於 24 小時插著電，如果電池已經老化膨脹，建議直接拆開底蓋將膨脹電池拔除，純插變壓器供電更安全。
